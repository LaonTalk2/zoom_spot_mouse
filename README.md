# 🔍 줌스팟 (ZoomSpot Web)

발표·강의·화면 시연 중에 **화면을 확대**하고, **화살표·사각형으로 주석**을 달고, **마우스 커서를 강조**하는 웹앱입니다.
ZoomIt과 SpotMouse의 기능을 브라우저에서 쓸 수 있게 만들었습니다.

## 실행 방법

설치할 것이 없습니다. `index.html`을 **Chrome 또는 Edge**에서 열면 됩니다.

시작 화면에서 화면 소스를 고릅니다.

| 선택 | 설명 |
|---|---|
| 🖥️ 화면 공유로 시작 | 모니터·창·탭을 캡처해서 그 위에 그립니다. |
| 🖼️ 이미지 불러오기 | 이미지 파일을 열거나 창에 끌어다 놓습니다. |
| 🎯 샘플로 연습하기 | 샘플 대시보드 화면으로 연습합니다. |

## 주요 기능

- **확대**: 마우스 휠로 1~8배, 커서 위치 기준으로 부드럽게 확대합니다.
- **주석**: 화살표, 사각형(채움 선택), 펜, 형광펜을 지원합니다. 확대해도 주석이 함께 확대됩니다.
- **색상·굵기**: 프리셋 6색과 컬러피커, 굵기 슬라이더를 제공합니다.
- **되돌리기**: 우클릭으로 마지막 주석부터 하나씩 취소합니다. 실행취소·다시실행과 전체 지우기도 됩니다.
- **스포트라이트**: 원형 하이라이트, 화면 어둡게, 링, 십자선 중에서 고르고 크기·투명도·색상을 조절합니다. 클릭하면 물결 효과가 나옵니다.
- **저장**: 현재 화면과 주석을 PNG로 저장합니다.
- 툴바는 3초간 입력이 없으면 숨고, 화면 하단으로 마우스를 가져가면 다시 나타납니다. 설정은 브라우저에 저장됩니다.

## 단축키

| 키 | 동작 |
|---|---|
| 휠 | 확대/축소 |
| 좌클릭 드래그 | 주석 그리기 |
| 우클릭 | 마지막 주석 취소 (주석이 없으면 확대 해제) |
| `Esc` | 확대 해제 |
| `Space` + 드래그 / 휠클릭 | 화면 이동 |
| `1`~`5` | 이동 / 화살표 / 사각형 / 펜 / 형광펜 |
| `R` `O` `Y` `G` `B` `W` | 빨강 / 주황 / 노랑 / 초록 / 파랑 / 흰색 |
| `Shift` + 휠 | 선 굵기 |
| `S` | 스포트라이트 켜기/끄기 |
| `Ctrl+Z` / `Ctrl+Y` | 실행취소 / 다시실행 |
| `E` / `Delete` | 주석 모두 지우기 |
| `Ctrl+S` | PNG 저장 |
| `F` | 전체화면 |
| `H` | 툴바 고정/자동숨김 |
| `?` | 도움말 |

## 한계

브라우저 보안상 운영체제 전체 화면 위에 직접 그릴 수 없습니다. 그래서 **화면 공유로 캡처한 영상 위에** 그립니다.
이 탭 자체를 공유하면 화면이 겹쳐 보이니 다른 창이나 모니터를 선택하세요.
바탕화면 전체에서 전역 단축키로 쓰려면 데스크톱(Electron) 버전이 필요합니다.

## 파일 구성

- `index.html`: 화면 구조 (시작 화면, 툴바, 설정 패널, 도움말)
- `style.css`: 스타일
- `app.js`: 확대, 주석, 스포트라이트 로직

순수 HTML/CSS/JavaScript로 만들었고, 외부 라이브러리를 쓰지 않습니다.
